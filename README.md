# 🐉 UU模拟器 — AI驱动文字冒险游戏平台

基于《龙族》世界观的自托管AI文字冒险游戏平台。纯前端、零依赖、打开即玩。

## ✨ 特性

- **🐉 龙族完整剧情** — 龙族I·火之晨曦主线剧情，40+场景节点，忠实于江南原著
- **🎲 TRPG战斗系统** — D20检定、属性加点、言灵对决、装备系统
- **🧬 深度角色创建** — 血统选择（白王/黑王/混血种/秘党）、出身背景、属性分配
- **🔮 六大言灵** — 天羽羽斩、君焰、时间零、雷池、审判、无尘之地
- **💾 完整存档系统** — 自动存档 + 手动存档，多存档位
- **🤖 AI集成** — 支持你（AI）实时生成剧情的导入接口
- **🎨 游戏风格UI** — 角色面板、状态条、背包网格、地图、战斗界面
- **🔧 创作工坊** — 自定义游戏模板，支持多游戏扩展

## 🚀 快速开始

### 方式一：直接打开

```bash
# 用浏览器直接打开
open uu-platform/index.html
```

### 方式二：本地HTTP服务器（推荐，避免CORS问题）

```bash
# Python 3
cd uu-platform && python3 -m http.server 8080
# 然后浏览器打开 http://localhost:8080

# 或 Node.js
npx serve uu-platform
```

## 🎮 开始游戏

1. 打开页面后，点击「登录」注册一个账号
2. 进入「游戏大厅」，点击「龙族：火之晨曦」
3. 创建你的角色：姓名、血统、属性、言灵
4. 点击「创建角色」进入游戏
5. 在剧情中选择你的道路，体验龙族世界

## 🤖 使用AI剧情生成

当游戏遇到预设剧情分支点时，可以使用AI导入功能：

1. 在游戏界面右侧点击「AI导入剧情」
2. 点击「复制状态」将当前游戏数据复制
3. 在聊天中粘贴给我（AI），描述你想做的事
4. 我生成后续剧情+选项，以JSON格式回复你
5. 把JSON粘贴回导入框，点击「导入剧情」

## 🏗️ 项目结构

```
uu-platform/
├── index.html           # 主入口
├── css/
│   └── style.css        # 完整UI样式（~20KB）
├── js/
│   ├── core.js          # 内核：路由、状态管理、IndexedDB存储
│   ├── dragonraja.js    # 龙族数据包：世界观、NPC、剧情节点树（~62KB）
│   ├── lobby.js         # 游戏大厅
│   ├── character.js     # 角色创建器
│   ├── engine.js        # 游戏引擎：叙事、战斗D20系统、存档（~35KB）
│   └── creator.js       # 创作工坊、AI导入工具
└── README.md
```

## 🛠️ 技术栈

- **纯前端** — HTML5 + CSS3 + Vanilla JavaScript
- **存储** — IndexedDB / localStorage（双保险）
- **零依赖** — 无需Node.js、无需Python、无需数据库，打开即运行
- **多模板架构** — 可扩展多个游戏模板（预留接口）
